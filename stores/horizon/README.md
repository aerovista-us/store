# Horizon Store Workspace

Horizon is a draft storefront workspace. It is isolated from Gear and is not
approved for preview or production deployment.

Current contents:

- `store.fixture.json` — schema and automated-test fixture only.
- Real catalog, merchandising, media, theme, content, hostname, provider
  mappings, and policies are intentionally absent.

Before creating preview files, complete
[`docs/HORIZON_STORE_DEFINITION.md`](../../docs/HORIZON_STORE_DEFINITION.md).
Do not replace the fixture suffix or change its environment without the Phase 0
business approvals and an isolated preview target.
