# Horizon by AeroVista

Public, customer-safe GitHub Pages artifact for the Horizon aerial-art
storefront.

- Preview: `https://aerovista-us.github.io/horizon-storefront/`
- Production hostname: `https://horizon.aerovista.us` through the shared
  Cloudflare edge Worker
- Commerce API: `https://api.aerovista.us`

The private source catalog, source masters, provider evidence, SQL, and
operator documentation are not stored in this repository. The `site/`
directory is generated and audited from the private AeroVista Store workspace.

Checkout remains disabled until the relevant product proofs and production
Square/Printful mappings pass.
