# AeroVista SOT manifests — aerovista-store

**Last updated:** 2026-08-26

This monorepo uses **layered SOT.json** manifests for portfolio scanning and canon audits.

| Manifest | Scope |
|----------|--------|
| [`../../SOT.json`](../../SOT.json) | **Monorepo root** — deploy surfaces, AVCC link, sub-manifest index |
| [`../../console/SOT.json`](../../console/SOT.json) | **console/** — Catalog Console v2 (store-console) |
| [`../../store/backend/SOT.json`](../../store/backend/SOT.json) | **store/backend/** — payment API (NXCore; gitignored) |
| [`../../horizon/SOT.json`](../../horizon/SOT.json) | **horizon/** — Horizon storefront |

**AVCC** (AeroVista Command Center @ https://avcc.aerocoreos.com) is a **separate repo** (`aerovista-command-center/`). It is not the catalog console.

Legacy template files in this folder (`SOT_AEROVISTA_TEMPLATE_GUIDE.md`, `SOT_EXAMPLE_NOTES.md`) remain for AeroVista SOT pack compatibility.

**Bridge manifest for AVCC:** `public/build-source-manifest.json` (generated by `npm run sync:all`). See [`../AVCC_INTEGRATION.md`](../AVCC_INTEGRATION.md).
