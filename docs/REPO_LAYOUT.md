# AeroVista Store — repo layout

## What gets committed (public repo)

| Path | Role |
|------|------|
| **`store/index.html`**, **`policy-content.js`**, **`favicon.svg`** | Canonical storefront |
| **`store/square_products_latest.json`**, **`storefront_overlay.json`** | Live catalog + overlay |
| **`store/img/`** | Product + collection-card images |
| **`src/`**, **`scripts/`**, **`docs/`** | React dev bridge, build tools, docs |
| **Root** `package.json`, `vite.config.ts`, `index.html`, `nginx/`, `.github/` | Tooling & Pages CI |

## Not committed (see `.gitignore`)

| Path | Why |
|------|-----|
| **`public/shop/`**, **`public/console/`**, **`public/store/`** | Generated by `npm run sync:*` |
| **`dist/`** | Build output |
| **`console/`**, **`archive/`** | Private operator tooling |
| **`store/backend/`**, **`store/scripts/`**, exports, pipeline folders | NXCore / local only |

## Sync & deploy

1. Edit **`store/`** → `npm run sync:store` (recreates **`public/shop/`** locally)
2. **`npm run build:pages`** → sanitized **`dist/`** → GitHub Pages (**gear.aerovista.us**)
3. Catalog console → **store-console.aerocoreos.com** (see **`docs/NXCORE_CONSOLE.md`**)
