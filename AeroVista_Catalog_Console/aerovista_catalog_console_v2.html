Recommended pipeline

  1. Load latest Square export (or catalog:refresh).
  2. Run Bulk Cleanup: names, descriptions, collections, variants.
  3. Pull Product Images (Square → store/img/, Printful fallback) for missing art.
  4. Run Validation and fix red issues.
  5. Export storefront JSON / Deploy to store.
  6. Export Square-style CSV only when you are ready to re-import data.

Do not publish until

  • No visible product has a missing price.
  • No public product uses Temp, Rental, MuseFace, or blank descriptions.
  • Product images are assigned for all promoted items.
  • Collections and tags are consistent.
